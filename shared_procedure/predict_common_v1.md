# 共通の予想手順書 shared-v1.0（Claude・ChatGPT 共通）

この手順書は、Claude と ChatGPT が**同じ手順で**メインレース（11R）の予想の確率（STEP1）を作るためのものです。
**買い目の作り方（STEP2）は含みません**（それぞれの方式のままです）。

## 読んでよい場所・読まない場所
- この手順書（`shared_procedure/`）と、馬場予測（`baba_models_v2/live/`）は、両者が読んでよい。
- 相手の予想・買い目・回顧・成績は読まない。Claude の `claude_track/predictions/`・`claude_track/reviews/`・`docs/data/predictors/`、ChatGPT の予想・PDF・レポートがそれにあたる。
- 手順書を直してよいのは Claude だけ（ユーザーの承認後）。直した日は下の「変更履歴」に必ず残す。

## 順序（変えない）
①オッズを見ずに全頭の評価・印を保存 → ②オッズ取得 → ③買い目 → ④固定。発走前に保存し、保存後は書き換えない。結果を見て予想を変えない。取得していないオッズ・データを推測で作らない（「不明」と書く）。

## STEP1：全頭の評価（オッズは見ない）
各馬について、次を材料に評価する。
- 近走の内容（着順・頭数・クラス・上がり）、今回と同じ競馬場・距離・馬場での実績。
- 斤量とその増減（やや強めに評価。3歳馬の軽斤量・前走からの増減。ただし斤量だけで決めない）。
- 脚質（近走の通過順位）と、メンバーから見たペース、枠・進路の影響。
- 当日の馬場（出馬表の馬場状態）。馬場の変化の可能性は不確実性として書く。
- **馬場の予測（福島・阪神のみ。ファイルがあるときだけ）**：`baba_models_v2/live/<日付>_<競馬場>.json`（朝8:45 JST に自動保存。オッズを使わない）を読む。`surfaces` のうち今回の芝/ダの `races` から `race_no`=11 を探し、`probs`（良・稍重・重・不良の確率）・`most_likely`・`p_change_from_morning` を、馬場の変化の見込みとして使う（道悪の確率が高いときは、道悪の実績を重く見る）。発走時刻は直近2年の中央値で代用しているので、確率は目安。ファイルが無い競馬場・日は使わない。使ったかどうかは保存内容に記録する（使わなければ null）。
- **前日の馬場傾向（記録のみ・勝率と印は変えない）**：前日が同じ開催のときだけ `docs/data/baba_bias/<前日の日付>.json` を読み、記録する。この数字で印・勝率を上げ下げしない（過去4年の検証で、当たり具合は良くならなかった）。
- 若駒・休み明けは減点せず、不確実性として明記する。
- **初めての距離（特に2歳戦の距離延長）**：その距離を走るのが初めての馬は、経験がないことを理由に確率を大きく下げない。近走の内容・血統・脚質から延長に向くかを評価し、他に材料が無いときも、同じ条件の馬より低く置くのは「やや」までにとどめる。
- 個別の好材料は、必ず総合順位へ反映する（書くだけで終わらせない）。
- 人気ではなく、能力・適性を評価する。

出力：全頭の `mark`（◎○▲△× または null）、`ability`（A+〜C）、`win_prob`（全頭の合計が1）、`top3_prob`、`reason`（その馬固有の根拠。馬名と数値で。不確実性も書く）。
