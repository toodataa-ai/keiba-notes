# 共通の予想手順書 shared-v1.3（Claude・ChatGPT 共通）

この手順書は、Claude と ChatGPT が**同じ手順で**メインレース（11R）の予想の確率（STEP1）を作るためのものです。
**買い目の作り方（STEP2）は含みません**（それぞれの方式のままです）。

## 読んでよい場所・読まない場所
- この手順書（`shared_procedure/`）と、馬場予測（`baba_models_v2/live/`）、STEP1の補助データ（`docs/data/step1_factors/`）は、両者が読んでよい。
- 相手の予想・買い目・回顧・成績は読まない。Claude の `claude_track/predictions/`・`claude_track/reviews/`・`docs/data/predictors/`、ChatGPT の予想・PDF・レポートがそれにあたる。
- 手順書を直してよいのは Claude だけ（ユーザーの承認後）。直した日は下の「変更履歴」に必ず残す。

## 順序（変えない）
①オッズを見ずに全頭の評価・印を保存 → ②オッズ取得 → ③買い目 → ④固定。発走前に保存し、保存後は書き換えない。結果を見て予想を変えない。取得していないオッズ・データを推測で作らない（「不明」と書く）。

## STEP1：全頭の評価（オッズは見ない）
各馬について、次を材料に評価する。
- 近走の内容（着順・頭数・クラス・上がり）、今回と同じ競馬場・距離・馬場での実績。
- 斤量とその増減（やや強めに評価。3歳馬の軽斤量・前走からの増減。ただし斤量だけで決めない）。
- 脚質（近走の通過順位）と、メンバーから見たペース、枠・進路の影響。
- 当日の馬場（出馬表の馬場状態）。馬場の変化の可能性は不確実性として書く。
- **馬場の予測（全競馬場・shared-v1.1〜）**：`baba_models_v2/live/<日付>_<競馬場>.json`（JRAの朝の馬場発表のあと9:15〜9:30ごろ自動で保存。オッズは使わない）を読む。**ファイルの日付が今日のものだけ使う**（前日のページから作ったものは無い。無ければ出馬表の馬場状態だけで評価）。`surfaces` のうち、今回の芝/ダの `races` から `race_no`=11 を探し、`probs`（良・稍重・重・不良の確率）・`most_likely`・`p_change_from_morning`（朝から変わる確率）を、**メインレース時間帯の馬場の見込み**として評価に使う。
  - 中身：全競馬場共通の過去データモデルに、当日朝の気象庁の降水確率（朝の発表のあと・発走までに1mm以上降る確率）を差し込んだもの。`probs` が最終の確率で、比較用に `probs_no_forecast`（予報なし）と `probs_morning_persists`（朝の馬場がそのまま続く）も入っている。`forecast.pops` が空のとき（予報が読めなかった）は予報なしの確率になっている（`model` の欄に書いてある）。
  - 使い方：道悪の確率が高いときは道悪の実績を重く見る。`probs` が朝の馬場とほぼ同じ（変わる確率が低い）ときは、朝の馬場のまま評価してよい。発走時刻は直近2年の中央値で代用しているので、確率は目安。降水確率の差し込み方は近似で、実際の当たり具合はこれから記録（`baba_models_v2/going_log/`）で確かめる。
  - 使ったかどうかは保存内容に記録する（使わなければ null）。
- **前日の馬場傾向（記録のみ・勝率と印は変えない）**：前日が同じ開催のときだけ `docs/data/baba_bias/<前日の日付>.json` を読み、記録する。この数字で印・勝率を上げ下げしない（過去4年の検証で、当たり具合は良くならなかった）。
- 若駒・休み明けは減点せず、不確実性として明記する。
- **初めての距離（特に2歳戦の距離延長）**：その距離を走るのが初めての馬は、経験がないことを理由に確率を大きく下げない。近走の内容・血統・脚質から延長に向くかを評価し、他に材料が無いときも、同じ条件の馬より低く置くのは「やや」までにとどめる。
- **この距離での過去の成績（shared-v1.2〜・ごく小さな補正だけ）**：その馬の過去の出走のうち、今回と同じ距離帯（200mごと。例：1,500〜1,700m→1,600m）での3着内率を、全体の3着内率と比べる。次の式で数字にする。①全出走の3着内率 base ＝（全体の3着内回数＋0.75）÷（全出走数＋3） ②同じ距離帯の率 ＝（その帯の3着内回数＋base×3）÷（その帯の出走数＋3） ③差 apt ＝ ②−base（同じ距離帯の出走が無ければ 0）。**勝率の見積もりに、倍率 exp(0.7×apt) を掛ける（apt を±0.15 で打ち切る＝倍率はおよそ0.90〜1.11の範囲）**。掛けたあと全頭の合計が1になるよう直す。例：apt＝+0.10 なら約×1.07、−0.10 なら約×0.93。
  - 根拠（2022-07〜2026-11 のJRA約14,400レース、オッズを使わない能力モデルに足した検証）：後半の対数損失の改善 +0.0016（95%幅 +0.0005〜+0.0027）で、係数の向きは前半・後半とも同じ。効果は小さい（標準偏差約0.08で勝率の比が約±6%）。**延長・短縮そのもの、過去の延長・短縮での成績の癖、最も得意な距離の帯は効果が確認できなかったので使わない**（延長・短縮は既存の「初めての距離」の注意だけ）。
  - 注意：この項目は市場も織り込んでいる（オッズ比較では、実績のある馬ほど人気になりすぎて妙味は無い）。**確率の見積もりの精度を上げるための補正で、妙味の根拠にはしない**。補正を掛けたかは `reason` に一言書く（例：「この距離帯3着内率が高く+5%」）。**shared-v1.3 以降は計算済みの `mult_dist`（上のファイル）を使う。ファイルが無いときだけ、この式で自分で計算する**。
- **過去データ分析から採用した3つの補正（shared-v1.3〜・計算済みのファイルを読む）**：`docs/data/step1_factors/<日付>_<競馬場>.json`（開催日の朝に自動で保存。その日のメインレースの全頭分。**ファイルの日付が今日のものだけ使う**。無い・その馬が無いときは補正なし＝倍率1.0で、`reason` に「補正データなし」と書く）。馬ごとに次が入っている。
  - `mult_trainer`：調教師の強さ（その調教師の過去のJRA成績の3着内率−全体。走数が少ないと全体へ縮小。レースによらない調教師の絶対的な強さ）。
  - `mult_kick`：上がり順位のよさ（直近3走の上がり3Fが、そのレースの出走馬の中で何番目だったか。速い順位が続くほど上がる）。
  - `mult_dist`：この距離での過去の成績（shared-v1.2 の補正と同じ計算を済ませたもの）。
  - `mult_total`：3つの積。**自分の見積もりの勝率に `mult_total` を掛け、全頭の合計が1になるよう直す**（自分で式を計算し直さない）。例：mult_total が 1.30 の馬は、同じ見積もりの馬より約3割勝率が上がる。
  - **二重に数えない**：上がり順位・調教師の強さは補正に入っているので、自分の評価では「上がりが速い」「厩舎が強い」ことだけを理由に勝率をさらに上げない（他の根拠は従来どおり）。
  - **各馬の `reason` に、`kick_reference`（直近3走の上がり3Fの順位。例：「1位/12頭(33.7)・2位/9頭(33.0)」）を必ず参考情報として書く**。順位が分からない馬は「上がり順位は不明」と書く。補正を掛けたこと（`mult_total` の値）も一言添える。
  - 根拠（2022-07〜2026-11 のJRA約14,400レース、今回のオッズを使わない能力モデルに足した検証、後半7,710レースの対数損失の改善）：調教師 +0.0044（95%幅 +0.0015〜+0.0071）、上がり順位 +0.0030（+0.0006〜+0.0053）、2つで +0.0073（+0.0037〜+0.0110）。係数の向きは前半・後半とも同じ。**標準偏差1つ分で勝つ確率が何倍になるか：上がり順位 約1.33倍、調教師 約1.16倍**（既存の最も強い要素＝走破タイムの指数は約1.53倍、序盤の位置取りは約0.75倍。一覧は仕組みページ）。補正は標準偏差の±1.5倍で打ち切る（調教師 約0.80〜1.25倍、上がり順位 約0.65〜1.53倍）。
  - 注意：オッズに織り込まれている情報も含むので、**確率の見積もりの精度を上げる補正で、妙味の根拠にはしない**。9項目を試して2項目が残ったため、偶然の可能性は残る。20レース単位の記録（通常のログ損失）で実際の効きを見ていく。
- 個別の好材料は、必ず総合順位へ反映する（書くだけで終わらせない）。
- 人気ではなく、能力・適性を評価する。

出力：全頭の `mark`（◎○▲△× または null）、`ability`（A+〜C）、`win_prob`（全頭の合計が1）、`top3_prob`、`reason`（その馬固有の根拠。馬名と数値で。不確実性も書く）。
