# JRA STEP2 購入セット優先比較 v1

## 意図
1頭を軸にした馬連・ワイドの流し、馬単マルチ、三連複・三連単のBOX・フォーメーション・2頭軸流しなど、**丸ごとの購入セット**を候補として列挙し、買い目単体中心の旧STEP2と比較する。全ての購入方式を無条件に優先するわけではない。正式なSTEP1・印・オッズ非参照固定・全着順確率分布を変更しない。

## ロジック
- 旧正式v3.13のもとになるv3.12 **100円固定選択**（増額前）をベースラインにする。
- オッズ未確認の個別買い目が1点でもあれば、そのセット全体は採用対象から除外する。
- `expandStrategy` で計算した**実際の全買い目と対応するソース実オッズ**が完全に揃った候補だけを扱う。点数だけで「BOX／流し」と誤称しない。
- 最多24グループ、最大2グループの重複なし組合せを探索。基準購入券を残余の資金で維持し、各案の計6,000円以下、組合せ的中確率、期待純利益、損失確率を全着順の同時分布から計算。
- 採用し得る案の制約：中央シナリオの期待純利益がプラス、基準期待純利益からの許容差は **2%か100円の少ない方**、集合的中率低下は最大0.5ポイント、損失確率悪化は最大1ポイント、下振れシナリオの期待利益悪化は最大200円。
- 表記の簡潔さは実際に賭けられる購入操作コマンドで計測する。BOXなどの候補がすでに旧最終セット内で**完全一致で表せる場合**、基準の操作回数をその分だけ小さくする。意味のない単純な分割より購入操作が減らない案は優先しない。
- 購入方式を優先する判定は上記のガードを全て満たして購入操作数が減る場合のみ。探索は**有限の局所比較**であり全局最適の証明ではない。

## 正式化の境界
v3.13には「v3.12の選択馬券を変えないこと」という正式検証契約がある。そのためこのモジュールでは `activated` を「旧方式より改善する**非公式の比較候補あり**」として返し、**過去／現行の正式`final_bets`を書き換えない**。単勝の100〜1,200円の増額も、最終的に採用されるセットの選択が固まってから、現行の検証済みルールを適用する必要がある。
公式STEP2への昇格はモデルのversion改定、対応バリデータ、新方式を実レースの発走前情報で検証、PDF・HTML・サイトへの正しいグループ表示、差分なしの過去断面検証を経たときのみ。

## 確認方法
`node .github/scripts/test-jra-set-preference-v1.mjs`で想定レース・取得不能ケース・旧実レース2本をオフライン再生。過去の保存ファイルSHA、STEP1、JRA本番予想には書込まない。

## 公開状態
本機能は研究用であり、正式な購入推奨として自動公開しない。候補の研究実装を検証できたことと、正式予想で買い目選択に採用されたことを明確に区別する。
