# JRA走破時計の取得修正と時計能力評価Shadow v3.17

## 今回の改修
- 1分未満の芝・ダート時計 `54.4` と分を含む時計 `1:08.1` の双方を、**距離・芝/ダート・馬場状態に結びつけて**抽出します。斤量、上がり3F、着差とは区別し、レース完走を確認したのに時計が取得できない場合はエラーにします。
- GitHubの既存SHA固定された `jra-gather-live-v314.py` と、予想確定原本、過去のHTML/PDF・買い目・印は**改変しません**。新規レースに限るv3.17取得入口を追加しました。
- 取得できた時計を、能力評価研究用の**時計Shadow指標**へ取り込みます。正式なSTEP1印と勝率を自動変更しないのは、補正の妥当性と過去レースによる外部検証が未完了なためです。

## 時計Shadowの評価方法
過去に同一レースで走った**今回の出走予定馬3頭以上**について、開催日・競馬場・距離・芝/ダート・馬場状態・レース名がすべて等しい場合だけ、同レースの今回出走馬の中央値タイムとの差を求めます。距離1000m当たりに換算し、±1.5秒までに制限、90日の時間減衰で加重平均します。数値がプラスならその過去レースで比較群より速く、マイナスなら遅かったという記述に限定します。

重要：比較群は過去レース全体ではなく今回出走馬の一部であり、斤量・クラス・展開・馬場の交絡が残ります。レース日付をまたぐ絶対時計を単純比較していません。適合する同一過去レースが足りない馬は評価保留です。

## 検証対象
2026年10月12〜25日のJRA正式入力14ファイル・860走。正常時計789件はそのまま、芝1000mの欠損31件は公式出馬表から保存済みの元の `source_excerpt` により復元、実際に走破時計がない40件（中止・除外・取消・記録不足）は補完しない。 `.github/scripts/test-jra-clock-v317.py` で回帰テストします。

## リリース境界
1. 新規レースのみ `e2e_validation/requests/v317/*.json` を作成し、新しい `jra-generic-one-shot-v317.yml` を使います。v314処理とワークフローはSHA固定のまま保全します。
2. 新取得データの時計は正式レポートの過去走表にも表示されますが、形式上は従来のv3.13 STEP1モデルのままです。
3. 能力評価Shadowの値と根拠は `e2e_validation/clock-shadow-v1/<race_id>.json` に新規保存します。正式能力・オッズ・買い目は一切変えません。
4. **能力評価正式採用の条件**：発走前時点で取得できるデータだけを用いた時系列ホールドアウト、同条件・馬場状態・距離・斤量・レース格差の補正検証、欠損率・有効比較群の監査、勝率校正、予想精度・収益性のベースライン比較。事後結果を見た過去印の再固定は禁止です。
5. 過去の公開HTML/PDFの時計修正は、元の予想原本を編集せず、別名の閲覧用訂正版を発行してページ・PDFの一致検証後にリンク切替します。今回は公開済み原本のPDF再発行およびリンク切替は**未実施**です。

## 検証と公開手順
- コードの構文と、既存860走の実データ回帰をCIで検証。
- 新規JRA正式レースで発走前の証跡固定、8券種の全価格、正式購入セット、PDF全ページ検査、公開HTTP一致を別途検証。
- サイトのUI・表示リンクを触る場合はステージング検証、承認後に本番反映。地方競馬ShadowやE0/E1/E2の研究ファイルは変更禁止。
