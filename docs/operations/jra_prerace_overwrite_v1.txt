JRA 発走前の予想・買い目・公開上書き許可ルール v1
制定日：2026-10-11
ユーザー承認：発走時刻前の予想なら上書きしても良い。

【REV-00】定義
同じJRAレースの発走前に、正式な予想をやり直して新版を公開することを許可する。「上書き」とは公式サイトの現行予想として参照されるHTML/PDF/最終買い目・公開台帳の差し替えを指す。発走前に固定した旧prediction/snapshot/proof_commitを実ファイル単位で改ざん・削除する意味ではない。
旧版を公開ページに並列表示する必要はない。公式の今週ページと成績連動ページは各レースの最新の正式発走前版1件だけを表示する。

【REV-01】発走前のみ許可
GitHub Actions実行時に現実の日本時間とJRA公式race_context.start_atを比較し、現在時刻が発走時刻より前のときだけ公開差し替えを許可する。同じ日でも他のレースの発走時刻で代用しない。発走済み・発走時刻不明・時刻未検証は停止。
新しいSTEP1と最終買い目は必ず発走前に作成し、新しい証跡commitが発走前であることを確認する。新しい観測時刻を偽装しない。
新しい固定買い目は旧版より後に作成された正式版であることを確認する。

【REV-02】予測アルゴリズムは不変
この変更はv3.11のSTEP1/STEP2評価・①～⑨・馬場・予算6000円・8券種・集合最適化・PDFデザイン・WIN5除外を変更しない。
従前の「過去予想を変更しない」は既に完了したレース、固定済みのimmutable prediction/snapshot/proof_commit実ファイルを指す。発走前の公式公開参照（canonical）は本ルールにより新版へ更新可能。
発走後の反省会・結果・成績、および地方競馬のファイルは変更禁止。

【REV-03】正式な上書き公開手順
旧公開レコードのコピーを改訂履歴台帳へ保存 → 新版STEP1/STEP2の発走前固定とGit proof → HTML/PDF全ページを実物検品 → 旧レコードの参照リンク・印・採用買い目・e2e_prediction・proof_commitを一括で新正式版に更新 → GitHubコミット → GitHub Pages公開HTML/PDF/JSONのバイト単位確認。
1レースにつき現行レコードは1つで、旧版は履歴台帳とGit履歴・不変の予想原本から監査可能とする。
未検証、GitHub push失敗、公開HTTP不一致などは未完了と明示。旧成果物削除やproof_commitsの後知恵改ざんで辻褄合わせしない。

【REV-04】意図と優先順位
この文書は正式プロンプトv3.11に付随する「発走前の公開更新方式」に限って従来の公開済み重複禁止規定より優先する。発走時刻が過ぎた時点でこの例外は失効し、正式に凍結された最終公開版を保持する。
正式ロジックや過去原本の追記専用SHA監査、途中終了禁止補則の効力は変えない。
