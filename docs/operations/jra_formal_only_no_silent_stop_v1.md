# JRA正式メイン予想：未実行・途中終了の再発防止運用 v1
制定日: 2026-11-22 / 対象: ChatGPT側の正式JRAメインのみ

**本書は実行・検証の運用補助であり、正式モデル・印・STEP1/STEP2・購入方式・予算・既存のSHA固定原本を変更しない。Claude側のファイルとE0/E1/E2研究には触れない。**

## 今回の原因と原則
2026-11-22にユーザーから正式予想の実行指示を受領したが、研究副作用を含む経路を回避した後、研究なし代替経路を最後まで実行せず、東京・京都のメイン予想が発走前に保存・公開されなかった。指示の不足ではなく実行継続・完了判定の不足だった。

JRAメインに「正式な予想を出した」「見送りを事前決定した」「予想未実施」の3状態を厳密に区別する。予想未実施を見送り・購入0円の成績として記録してはならない。発走後に架空の予想・odds・final_bets・proof_commitを作らない。

## 翌開催日以降の実行手順
1. **着手確認**: JSTの対象日、公式JRA開催場と各場11R、各発走時刻、休日月曜開催を先に列挙する。開催場の数だけ対象レースIDを作り、各レースのチェック状況を追跡。開催カレンダーの暫定slugを公式番組と突き合わせ、誤ったslugのまま完了判定しない。
2. **研究なし経路に固定**: 最初から `.github/workflows/jra-generic-formal-only-v314.yml` のE0/E1/E2副作用を伴わない正式JRA入力/予想手順を選ぶ。調教・公式発走前根拠は必要だが、研究用のShadow収集が止まっても正式予想を一律停止しない。失敗した場合は根拠を保持した研究なし代替手順を確認し、無効な推測入力・市場価格の創作はしない。
3. **発走前の真の完了条件**: 既存SHA固定のv3.13 STEP1と正式v3.15 STEP2が成立し、全場の最終`final_bets`（買う/見送りを含む）、`proof_commit`、各レースの原本JSON・HTML・PDFを発走前に固定・保存する。v3.13のみの途中成果を正式完了と誤認しない。予想の後追い固定は禁止。
4. **公開物まで照合**: Actionsが緑でも終了しない。各競馬場について台帳 `docs/data/races.json`、発走前証拠、HTML・PDFが一致し、公開URLがHTTPで実際に開けることを確認する。必要なら読み取り専用の`--check-public`を使い、公開バイト整合性も比較する。
5. **全場チェックゲート**: `python3 .github/scripts/jra-formal-coverage-guard-v1.py --date YYYY-MM-DD` をGitHubリポジトリのcheckout上で実行し、全開催11Rが`OK`になるまで「全件完了」とは報告しない。GitHub Actionsの「JRA formal main day-level publication coverage (read-only)」でも対象日を指定して検証できる。対象なし・未登録・買い目なし（買うのに）・証拠なし・発走後固定・HTML/PDF欠損は失敗とする。
6. **エラーの取り扱い**: エラーがあれば、発走前に可能な安全なリカバリーを行う。対象ごとに「現在の阻害要因」「済んだ工程」「残り」「GitHub変更済ファイル」を明示する。時間不足・公式情報403・必要データ欠落などの真のblockerは隠さない。失敗したレースを黙って省略せず、発走前にそのリスクを利用者へ報告する。
7. **回顧**: 公式結果・払戻確定後に発走前固定済みのレースだけ回顧する。「未予想」は回顧・見送りや実績母数に紛れ込ませない。祝日月曜開催まで全メインがreviewedとなる前に週次改善を実施しない。

## チェッカーの特徴と限界
- `.github/scripts/jra-formal-coverage-guard-v1.py` は当日開催場を既存 `docs/data/jra_postrace_meetings_v1.json` の明示一覧から取得する。**本ファイルは暫定slugの手入力台帳であり、JRA公式開催番組との照合を代替できない。** 新しい開催日が未登録なら意図的にエラー。
- チェッカーは公式情報取得・予想作成・GitHub公開を行わない。検出と失敗通知は、誰かが実行したときに限る。ChatGPTの手動指示がなければ自動で予想が始まるわけではない。
- 独立して実行した確認が正常でも、確率・購入戦略の妥当性や全PDFの見た目を保証するものではない。既存の予想/E2E/PDFバリデーターも別途必要。
- この運用補助で旧版・Claude関連・正式プロンプト・発走前予想原本を変更してはいけない。
