# 京都芝2000m内回り v5 双ラチ原画像照合

## 前回の失敗と対応
v4は源画像から描き直したと言いつつ、実際には1本の中心線から一定16pxの帯を描いていた。実画像の芝帯と形状がズレる構造だった。今回は元画像(620×430)に映る**京都芝内回り**の緑の芝帯とダート(茶)の境界を基に内ラチを取り、別途、外ラチを写真上でトレースして2本の独立した走行線にした。1200m近辺と3〜4コーナーの白い分離帯、および1C入口のチュートを混同しないよう、形状を画像全体で照合した。60適応ノットで最大画像誤差0.48px（元の2,001点の抽出トレースとの比較）。

## 原画像の緑色との照合（自動抽出、診断値）
