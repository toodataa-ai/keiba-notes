# 東京芝2000m：ローカル原図照合 v2

2026-10-31。LAB限定、走路未承認、走行ロック継続。
基準main: `e6d0a59be4ba1b0f576dfcf0fb0569d284e22006`。
これは原図の静止検査を進める機能であり、完成したシミュレータではない。

## 原素材を公開しない方式

[うまぽっとの利用規約](https://umapot.com/?page_id=116)は素材利用を認める一方、無許可の再配布を禁止している。
原PPTX/ZIP、変換SVG/PNG、抽出された原図座標データはリポジトリにもPagesにも同梱しない。
原図は利用者の端末またはCIの一時ディレクトリで変換し、ブラウザのFile APIで読み込む。
ファイル内容をアップロード・保存するAPIはなく、読込後も再生や承認には接続しない。
CIのartifactにも原素材・変換SVG/PNG・原図を含むスクリーンショットは含めず、数値要約だけを保存する。

`audit-local.json` のPPTXハッシュと `source-local.svg` のSHA256を照合する。
JSONとSVGのペア一致は、第三者が作った任意JSONの内容を公的に認証するものではない。
信頼できる原PPTXから同梱の生成スクリプトで作成したペアだけを検査に使う。
改ざん・異なる原版・誤画像は停止し、古い画像・検査状態は破棄する。成功しても `canAnimate=false`。

## ローカルでの作成

必要: Python 3、Node.js、LibreOffice Impress、Poppler (`pdftocairo`, `pdftoppm`)。
[公式の素材配布ページ](https://umapot.com/?p=13273)から東京競馬場ZIPをダウンロードしてPPTXを取り出す。
PPTX原版のSHA256は `c6c372babca741439fe2c18857ea7d3fbccd42d115377448a836327ed53dc6c4`。
取得原版が違う場合は自動的に別形状を受け入れず停止する。

リポジトリのルートから実行する。

```bash
python3 tools/audit_tokyo_2000_source_v2.py --pptx /tmp/tokyo-source.pptx --out /tmp/tokyo-source-audit
node tools/audit_tokyo_2000_run_v2.cjs /tmp/tokyo-source-audit/audit-local.json
```

LABページの「ローカル原図と走路候補の静止照合」を開き、生成された `audit-local.json` と `source-local.svg` を一緒に選ぶ。
出力先はリポジトリ外に限定。生成フォルダは公開・Git追加しない。

## 原図変換と走路候補

- 原PPTXの2枚目をLibreOffice→PDF→SVGとして、そのまま表示に使用。低画質JPEGは使わない。
- 元の13:9の縦横比を維持し、全体図と拡大図でX/Yに同じ倍率を使う。走路や馬番の座標も両図で共通。
- 1枚目の2000m発走目印は90度回転したグループ内。親groupの回転、flip、chOff/chExt、shape変換を合成して位置を取り出す。
- 走路候補は、発走ポケット→外側2角→長い上側直線→左側3〜4角→下側ゴール直線。原図shape #10（ポケット）、#9（外側曲線）、#4（周回走路）、発走目印#93とゴール線#20を参照する。内側の別ルートへ短絡する点列を使わない。
- 画像はYが下向き。左回りの内側法線は `(ty,-tx)`。ポケットでは内側が西、向正面では南となることを検査。
- 既存の途中距離130/300/900/1145/1474.1mは測量座標ではない。候補では約100mで曲線に入るよう物理距離を配分するが、原図は距離目盛り付き測量図ではなく、この配分も仮説。
- 距離→原図弧長は単調Hermite補間。固定した境界を保ちながら同じ導関数でつなぐ。物理距離・タイムは編集しない。
- 東京は共通LaneAI設定でmaxLane=16（31m幅から算出）。初版の東京専用ゴール投影の既定値14を16に修正。京都、共通モジュールは変更しない。

PPTX原版は上記ハッシュ。ブラウザはChromium、幅390/1024px。

|最大横移動|3.65 lane/s ≈ 6.02m/s、自然さは未承認|
|不正SVG読込|ハッシュ拒否、旧画像・状態破棄、走行ロック維持|
|外部送信|静止原図照合テストでPOST/アップロードなし|

地点指定は固定0.08秒ステップで最初にその距離へ達した状態。実際の距離・時刻を画面に併記し、馬を指定地点へ強制移動しない。
余走は個々の実displayDで投影する。全馬を2032mで切り詰めず、先着馬の進んだ距離も保存する。

画素検査は原図SVGを2480px幅でラスタ化し、各点の中心と半径0.6原図pxの8方向をチェックする。
この0.6px円は検査用で、馬体や画面上の拡大された馬番丸の寸法保証ではない。
黒いゴール線付近では、SVG画像のラスタ化による1原図px以内のアンチエイリアスを黒/緑混合色として別集計する。
白・茶色はゴール線付近でも許容しない。芝緑だけで別走路への短絡を認定しない。

## 走行を解除しない理由

原図に沿う表示候補は、まだ共通RaceSimEngineの物理profileと統合していない。
既存物理側は130mまでchute扱い等、今回の候補と曲率・距離境界が一致しない部分がある。
今回の静止馬群・時計は従来の東京近似metricsによる数値計算であり、新走路での実走を検証した結果ではない。

複数seedの衝突安全、速すぎる横移動への対応、3〜4角の物理半径/勾配整合、1/2/4倍の実時間再生、
固定ゴールカメラへの向き連続、時計/着差HUD、厳密な走路分岐トポロジー監査とユーザー目視は未完了。
原図画素が全て緑・18頭完走という理由だけで走行許可にしない。
`RaceTokyo2000.assertCanAnimate` は引き続き無条件停止。既存rolloutは未変更。

実装後もLAB未承認。STAGING・本番・正式予想データへ移行しない。
