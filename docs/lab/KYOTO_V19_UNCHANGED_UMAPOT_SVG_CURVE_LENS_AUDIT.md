# 京都芝2000m内回り — LAB v19 元画像を守るカーブ実況の拡大補正

## 制約（ユーザーの最重要条件）
うまぽっと原本の無地ベクターSVGは改変しない。芝・ダート・コース形状・内ラチの書き直し、JPEG引き伸ばし、横方向への画像展開は禁止。全体図と実況は同じ`docs/lab/assets/kyoto-umapot-course-clean-v8.svg`を利用し続ける。

## 技術的原因と対応限界
京都芝2000mの3・4コーナーでは実物の馬間距離が同じでも、俯瞰イラスト上の2点間の**弦長**はカーブで短くなる。コーナーから直線へ移ると同じ群が広がって見える。原図の実形状を保ち、馬番の正確なコース上の位置を維持する限り、すべての実距離を2次元直線距離と完全一致させることは数学的に不可能。

対策：純粋な平行移動＋**全体を一様に拡大するカメラ**のみを使う。65mの代表的な固定実走行間隔をコースの各地点で原図上の弦長として測定、縮んで見える区間では緩やかにズームを増やす（既存のスマホ8.8倍／PC9.7倍を基準、増分は最大1.45倍）。48m前後の区間で拡大係数をならし、進行距離で単調・連続なカメラパラメータとする。先頭追跡カメラは馬群重心を追う代わりに、先頭の物理距離から10m手前の原図コース位置を参照する。オッズ・レース結果・走行位置など一切変えない。最終80mは従来の京都1400式GOAL固定カメラを優先。
