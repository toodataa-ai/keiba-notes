# LAB v23：横展開可能な実況／全体図／着差 UI

2026-10-19 JST。LABのみ。正式予想、買い目、PDF、STAGING、本番への変更なし。

- 共通モジュール RaceBroadcastHud はコース名・回り・距離・馬名をハードコードしない。元の RaceSimEngine が供給する time, splitTime, splitDistanceM, horse.finishTime, horse.runoffSpeed, horse.name, allCrossedAt のみを利用する。
- PCでは左右、モバイルでは上下へ実況と全体図を同じパネル内に表示。順位欄は不可視（旧診断のDOMのみ残す）。
- 大きな時計を右上に固定。1.00.0形式で前半通過時計を直下に表示。各馬がゴールした瞬間から上位3頭の馬名を順次表示し、全馬ゴール後に全着順・時計・前馬との推定着差・勝馬との差を表示。
- 着差はゴール時のシミュレーション速度と通過時間差から1馬身2.4m換算した概算。公式JRA着差と混同させない。
- 原SVGのベクター画像パス、サイズ・図形を変更せず、ブラウザー内でのラスタレイヤーキャッシュを強制する will-change 指定を解除。コース経路計算、速度、進路はそのまま。
- 他コース横展開時はデータ定義とコース画像の差替のみが基本。共通HUD、時間・着差変換を変更してはいけない。iPhone実機の目視確認とGitHub ActionsのChrome/WebKit検証が合格するまで本番反映は禁止。
