# LAB 京都芝2000m内回り・18頭立て内優先検証 v0.48

## 目的・仕様
- 本番未公開のシミュレータのため変更先は**LABだけ**。
- 京都芝1400m外回りと同一の `RaceLaneAI` / `RaceSimEngine` を使用。別の京都2000専用レーン判断コードは作らない。
- 18頭全員架空。逃げ2・先行5・差し6・追込5。固定シード2026と再現可能な生成手順を採用。
- 初期ゲート横方向位置は外枠まで広がるが、実際のレーン選択に従いスタート直後から内へ寄る。内が塞がれば無理に割り込まず、空いたら内へ戻す。
- 実況も全体図も `RaceUmapotOverlay.point(profile,d,lane)` の全く同一の画像上座標を利用。画像のカメラ拡大・平行移動しか異ならない。
- 18頭表示時には実況の番号サイズを縮小。馬群の広がりによってズームを自動調整し、全頭を収める。
- 旧1頭デモは `?demo=shuka-one` のまま利用可能。

## 検証方法と制限
- Node `tools/test_kyoto_inner_18_lane_v048.cjs`：実レーンエンジンを940ステップ程度実行し、固定シード、内寄せ、全18頭と実況/俯瞰共通座標、最大横速度を検査。京都1400mも同じレーン制御器を使用することを確認。
- Playwright：390px/1024pxでブラウザを開き、実際に元画像を使って走行する18頭を100/310/530/900/1270/1672/1900mで撮影。18頭表示、枠色、欠損なし、元画像・JSの読み込みと位置一致を確認する。
- 交通詰まりのメトリクスには全走行中の繰り返しステップの合計値が含まれ、割合ではない。
- 視覚上の全頭判別・芝帯端との厳密な物理距離は**人の目視が必要**。画像は測量データではないので「厳密に内ラチから何メートル」まで保証できない。
- 画像自体の不要な文字・補助線のマスクは別段階。外部素材の再配布はせず、ライセンスと視認性を確認してから判断。
- 本番・ステージング・正式予想・買い目・PDF・発走前proofは変更しない。
