# 京都芝2000m内回り・LAB v8 正本変更監査

## 変更理由
スマホ実況が拡大JPEGのため粗い。18頭を京都1400同様の実走行位置に描くと27px前後の丸番号が著しく重なる。コース線の再トレースはユーザーが不承認。

## 元画像の扱い
配布元: <https://umapot.com/?p=13277>（フリー素材のPowerPoint原本）。利用条件: <https://umapot.com/?page_id=116>。
2020年京都コース原本ZIPから2枚目PPTXを採用。5個の上位シェイプのうち純粋なコースのgroup shape ID37を原状のまま保持。他の4個（title×2、GOALグループ、右回り矢印グループ）だけ除去。
LibreOffice経由のPDFからベクターSVG化した経路は元のベジェを含み、模写でもAI補間でもない。SVGは`docs/lab/assets/kyoto-umapot-course-clean-v8.svg` 620×430寸法で両ビューに共通に表示。リンク先原本のZIPなどは本リポジトリに同梱しない。

## 動き方と番号
- `RaceLaneAI`・`RaceSimEngine` は京都1400と完全共通。スタート直後に安全をチェックして内側へ、障害時には必要な外追越し、脚質と前半ハイペース時の差し/追込みを既存のエンジンで計算。
- 番号丸は京都1400 `raceNumberMarker` の移植、物理位置からの一切の表示位置変更なし。
- スマホは非追跡馬0.62倍・追跡馬0.82倍、PCはそれぞれ0.72/0.90倍。カメラ最大スマホ8.2倍/PC9.6倍で「大きな馬番丸が密集する」問題を緩和。全18頭が極端に密集すれば部分重なりはあり得る。行方不明にならないよう隊列バーは18頭を常時表示。
