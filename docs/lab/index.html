本番リリース時の安全ルール

  1. 完成候補をステージングで確認し、明示的に承認する。
  2. 変更ファイルを画面系だけに限定し、最新の races.json、HTML/PDF、買い目、発走前proofを上書きしない。
  3. 変更前後のGit tree/blob SHA、表示、公開HTTPのバイト一致を監査する。不一致なら公開完了としない。
  4. 新しい機能と単なる古い検証資料を混同しない。LABからの自動本番昇格はしない。
