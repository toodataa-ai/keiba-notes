# LAB v0.51 — 京都芝2000m実況のズームと芝帯形状の修正

## 前版の不合格
ユーザーの画像から、v0.50では1番が突出して巨大、18頭の番号が密集して判別できず、芝帯の輪郭が不規則なギザギザになっていると確認した。従来の単体検証は「同じ座標」「緑色の画素上」などの性能以外の条件しか扱っていなかった。

## 修正
- 京都芝1400外回り同様、追跡馬付近110m以内の馬群の広がりによってカメラをフレーミングする。最大4.6倍（単独5.2倍）で極端なアップを抑える。表示領域に余白を確保。
- 18頭時の番号を通常0.92・追跡1.02倍とし、突出した1番の大きな輪を抑える。元の全体図で全馬を引き続き追跡。
- 芝帯は原画像から抽出した5mごとの緑芝帯境界を表示専用に平滑化。幅45m程度の対称重み平均と二次補間。元の計測境界から動かす量は最大3px。内外レーンの実際の走行位置は変更しない。
- ベクター図・不要な文字や補助線の非表示は引き続き維持。本番・STAGING・正式予想データを触らない。

## 検品
- 修正前スクリーンショットを不合格根拠とし、サンプルポイントの数だけで合格にしない。
- 390px/1024pxで0/100/310/530/900/1270/1672/1900m、18頭の番号の重なり、カーブの自然さ、全体図との位置整合を目視監査。
- カメラ範囲、二次曲線描画、元境界から最大3pxの移動、別コース退行なしを自動検査。

LAB公開のみ、ユーザーの目視承認待ち。
