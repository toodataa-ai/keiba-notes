# 京都芝2000m内回り LAB v17 — 0〜2000m全区間の「馬群が急に縮んで見える」表示補正

## ユーザー指摘
2026-10-19向け作業指示：1400m付近で急に馬群が詰まる。ほかにも同じ表示の問題があればあわせて修正する。

## 根本原因
- 共通RaceSimEngine / RaceLaneAIによる馬間距離は、前方消耗や追走補正で中盤に段階的に縮まる。架空18頭を同一seedで再計測すると、**1440〜1460mの実際の先頭〜最後尾の縮小は約0.86m**。
- うまぽっとの原画像は測量データではなく図解。各地点の「レース1mを元画像で何pxに描いたか」が大きく違い、従来の描画では1440〜1460mだけで**約4.73px（スマホ倍率8.8で画面約42px）**も集団両端が縮んで見えた。
- 全区間の追加監査では1コーナー（320〜390m）、2コーナー（530〜640m）、最後の直線入口（1700m付近）にも同様の描画縮尺差を発見。物理エンジン自体は変更不要。

## 実装の原則
- `docs/lab/race-clean-turf-mask-v1.js` 内のsourceDistanceを、コース全2000mの**元SVGに沿った弧長の単調な写像**に変更。
- **0, 308.7, 530, 720, 1270, 1435, 1671.6, 2000m**の画像上の地点は一切移動しない。小数境界も補間ノードとして厳密保持。各境界の進行率は前後区間の弧長進行率の調和平均を用いるC1連続のHermite補間。
- 1400m近傍は総区間一律方式だけだと圧縮の変動を別の地点へ移すため、実績のあるv16の3/4コーナー弧長較正を内側45mブレンドで維持。距離変換は約13m以内の画像上位相調整で、同じ実芝帯上の画像を移動する。
- `RaceSimEngine` の実距離、スタミナ、脚質、追走補正（京都1400共通）、レーン、馬券、ゴールの時計、結果は一切変更しない。馬番の絵は原図の芝帯内のみ、全頭同サイズ。
- 画面HTMLが`race-clean-turf-mask-v1.js?v=20261019-17`を読み込み、新旧キャッシュ混在を防止。
