# 京都芝2000m LAB 新設計 clean-course-v1 — ユーザー確認用

## なぜ旧版を使わないのか
LAB v0.49〜v0.52はうまぽっと原画像の芝色から401点で内外境界を検出し、実況の高倍率表示で輪郭が波打った。画像の不要印刷物・馬番の巨大化・ライブカメラのジャンプも発生した。自動検査成功でもスマホの画面品質は満たせなかったため、旧コードに場当たり補正を加えるのを中止。

## 新しい設計
- 新しい独立ページ `docs/lab/race-clean-course-v1.html`（旧版は比較用に保持）
- コースの正本は `docs/lab/race-clean-course-v1.js`：5区間（直線3つ・ベジェのコーナー2つ）。
- スタート〜308.7m、2C出口530m〜3C入口1270mは厳密な直線。コーナー境界で接線方向が一致する（C1方向連続）。
- 各距離`d`の内外ラチベクターの間に物理レーン`lane`を投影し、同じ`RaceCleanCourse.point(d,lane)`を両画面で使用。
- 高DPIのCanvasにベクター描画。JPG拡大・画像の緑色しきい値・距離補助線・印刷文字は不使用。
- 馬群制御は既存`RaceSimEngine`／`RaceLaneAI`を変更せず同じ京都1400型の内寄せを使用。架空18頭のみで正式予想と完全分離。
- UIは「実況は主要馬群のアップ」「全体図は全コース」「馬番と枠色は共通」。
- 既存LABの旧画面から新画面へリンクを設置するのみで旧機能は保護。

## 残課題（不合格扱い）
**18頭の密集場面での馬番の重なり**。ゲート直後は横位置・距離が近いため、正確な座標を1つずつ描くと一部の数字が物理的に重なる。画像輪郭は改善したが、「全18頭が常時読める」条件は未達。馬の位置を偽装しない表示補助の設計が必要。

**コースの測量精度**。今回の620×440ベクターは距離地点と右内回り構造を持つ、設計用の幾何学的近似。JRAやうまぽっとの画像そのものの再トレース・正確な測量座標ではない。芝幅や曲率の目視審査は未完。
