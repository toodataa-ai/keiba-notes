# 京都芝2000m内回り LAB Clean Course v3 — 原画像芝帯との位置合わせ

全体図はうまぽっとの原画像620×430（外部画像の直接表示）と馬番だけ。実況は元画像の外形に合わせたベクターコースで、拡大で画像を粗くしない。走行エンジンは18頭の架空馬のみ。正式予想・買い目・PDFとは接続しない。

## v2で判明した問題とv3対応
- 旧描画は描画自身の仮想芝帯に対するin-bandテストのみ。2026-10-18に取得した390px/1024pxの公開CIブラウザスクリーンショットを比較すると、原画像の茶色い部分へ馬番が重なる地点があった。
- 既存の元画像が入った全体図を8地点で重ね、馬番重畳を外した参照画像の緑色領域に対して、0〜2000mを5m刻みで画面法線方向へ補正。18px幅員を用い、画像で内側0列から外側14列までを比較した。401サンプルの補正を許容誤差1pxで26ノットに簡約した。補正は共通の距離→画像座標のみへ適用し、競馬の物理レーン・速度・順位・時計に適用しない。
- 内回り芝A幅員はJRA公式に合わせ27〜38mへ訂正（24〜38mは外回りの値）。
- 密集した馬番の物理位置を偽装せず、実況の下に全18頭の隊列を読める形で表示し、番号を選択してズーム追跡できる。
- この補正値は**京都2000m内回りの画像固有**。他場では同じ変換処理と画面色監査を利用し、画像固有の補正値を個別生成する。無検証で数値を使い回さない。

## 未承認・注意事項
うまぽっと原画像は測量図ではない。画像上の着色から算出した可視化用座標であってGPS・競走馬の実測位置ではない。画像の緑帯に合わせた確認と実機スクリーンショットの目視受入れは残る。LAB限定で、STAGING/PRODUCTION/DATAには反映しない。
