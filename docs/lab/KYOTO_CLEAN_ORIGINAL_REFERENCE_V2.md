# 京都芝2000m内回り LAB Clean Course v4

## 不具合の原因と対応

前v3の距離ごとの横方向補正（26ノットの線形補間）は芝帯の法線を不連続にし、区間ごとのコース塗りが重なることで実況画面に角が出た。原画像との比較でこれを確認し、**補正テーブルの積み増しを廃止**した。

元のうまぽっと原画像620×430pxの京都**内回り**芝帯に沿い、1角/2角/向正面/3角/4角/直線の独立した画面上座標を登録。曲線は弧長でパラメータ化した後に、全体を1m間隔の2001点に統合し、Hermite補間で継ぎ目をC1連続にする。実況も俯瞰も同じ走行点を使用する。表示コースのラチは中心線法線から求め、全区間をひとつの芝帯として描画する。ベクター拡大のみで原画像JPEGを実況表示に拡大しない。

18頭の物理座標は変えず、馬番のみ画面上の衝突回避でずらす。ずらした番号は小さな元位置ドット/細い線と関連付ける。実況画面下の18頭隊列は従来どおり維持する。

## 安全性
この走行形状は元画像を参照した**可視化用の近似**であって測量・GPS値ではない。距離、幅員などのJRA参照値と画像座標は別管理。実馬・予想、買い目、PDF・正式Shadowとは非接続。LAB以外の本番UI、ステージング、DATAは変更しない。

## 残る受け入れ条件
形状が完全一致したことを自動試験だけで証明できない。iPhone/PCの実ブラウザで8地点×18頭の走行曲線と馬番可読性を目視確認し、ユーザーの承認を得るまで未完了。外部原画像は画像提供元の配信状態に依存する。
