# 京都芝2000m内回り・うまぽっと原画像との形状照合（2026-10-18）

## 結論：**不合格／未承認**
2026-10-18のLAB Clean Course v4で、C1連続性・直線・18頭の馬番衝突のCIは成功している。しかしそれらは**原画像との幾何学的一致を保証しない**。元画像からスクリーンショットを取得して重ね合わせたところ、走行線と芝帯位置が合わない区間を確認した。

## 実施した照合
- 原画像：`https://umapot.com/data/powerpoint/kyoto_couse/kyoto_couse_1.jpg`。LAB Playwrightの `overview-1024-0.png` から馬番2つが残る実画像を取得し、620×430にリサイズして内部監査。
- 対象：v4の7区間の中心線（弧長で2001点、毎1m）、走行レーン0/2/4/6/8/10/12。
- 方法：画像をHSVで緑色候補として抽出し、線の座標周囲2pxの緑領域への包含を測る。文字・馬番・元画像の破線・凡例があるため「緑にない」すべてがコース外ではないが、数十〜数百m続く欠損は座標ズレを示す。
- 参考値：中心線89.5%、最内側lane0 78.7%、lane2 81.8%、lane4 84.8%、lane6 88.3%、lane8 91.2%、lane10 93.9%、lane12 93.2%。
- 局所例：lane0の300〜400m区間約58%、900〜1000mは0%、1000〜1100mは0%、1100〜1200mは0%。元画像の文字による偽陰性を含みうるが、lane12は同区間で緑に留まっており内側のラインの登録が不適切と判断する。
- コースの描画幅は16pxの一定値で、画像の緑帯の幅やコーナーの膨らみを再現しない。中心線の連続性の試験はこの問題を検出できなかった。

## 判定基準の改定
- 滑らかさのCIが通っても「元画像一致」「コース完成」と書かない。
- 元画像の内外ラチをそれぞれ距離連続の輪郭としてトレースし、馬番の物理座標を芝帯外に出さない。内回り・外回りの別コースの帯を混同しない。
- 一定幅の法線オフセットだけで元画像と同一だと主張しない。画像上の芝帯幅・接線を継続して評価する。
- スタート、1C、2C、向正面、3C、4C、直線入口、ゴールまで全周を比較し、スクショと数値指標で受入れを行う。
- ソース画像には文章やガイドが描かれているため、色の包含率だけで正式合否を決めず、局所的なラチ輪郭と目視を併用。

変更の対象は今後もLABのみ。本件の調査だけでは正式予想・買い目・PDF・本番シミュレータ・STAGINGに変更なし。
