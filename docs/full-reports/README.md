# 完全版予想アーカイブ運用ルール

KEIBA AI NEXT では、JRAメインレースの公式PDFは **発走前に確定した完全版の authored HTML（完成版HTML）** からのみ生成・保存・公開します。

## 必須ルール

1. 予想は発走前に完全版として確定し、その時点の完成版HTMLを保存する。
2. 完成版HTMLには、本文だけでなく CSS、色、評価グラデーション、フォントサイズ、罫線、表、2カラム配置、ページ構成など **見た目を構成する情報をすべて含める**。
3. 結果を知った後に予想本文を作り直したり、追記で内容を都合よく変更したりしない。発走前スナップショットは不変とする。
4. 全出走馬の診断を保存する。`races.json` の `field_size` と全頭診断数が一致しなければ公開用PDFを生成しない。
5. 発走時馬場予測、馬場質、バイアス、類似条件タイム、同条件直接実績、STEP1、展開・隊列、再監査、全頭診断、◎弱点監査、STEP2、能力本線、期待値追加、緊急リスク、推奨買い目、最終結論を完全版の必須要素とする。
6. 要約ページだけを公式PDFとして保存してはならない。
7. 結果・収支・回顧は、発走前予想のスナップショットとは分離して管理する。
8. プロンプトを改良した場合は `docs/data/prompt_history.json` に変更内容と理由を記録する。

## PDF生成の恒久ルール

- 公式PDFの入力は `docs/reports/*.html` にある **完成版HTMLそのもの** とする。
- 2026-10-04以降の公式HTMLには `data-full-report="true"` と `data-authored-report="true"` を付ける。
- PDFは **WeasyPrint 68.0** に固定して生成する。レンダラーを勝手に変更しない。
- HTMLから抽出したプレーンテキストを `<pre>` に流し直してPDFを再構築してはならない。
- `.txt.xz.b64` は内容確認・災害復旧用のテキスト資料に限定し、公式PDF生成元としては使用しない。
- `data-reconstructed-from-text="true"` のHTMLは公式PDF生成を自動的に失敗させる。
- ページ数と全頭診断数を自動監査し、不一致なら公開用PDFを更新しない。

## 2026-10-04 の復旧について

毎日王冠と京都大賞典は、当日に作成済みだった **元の完成版HTML/PDF** を復旧しました。色・文字サイズ・罫線・表・評価色・ページレイアウトを含む authored HTML を `docs/styled-report-sources/` に圧縮保存し、そこから `docs/reports/` を完全復元します。

`docs/styled-report-sources/` の復旧ソースには SHA-256 の整合性チェックを掛け、内容が変わった場合はPDF生成を失敗させます。これにより、プレーンテキスト版へ戻ったり、見た目が別物に置き換わったりすることを防止します。

今後の新規予想は復旧用圧縮ファイルを通常運用には使わず、**発走前に完成した authored HTML をそのまま `docs/reports/` に保存する**ことを標準とします。
