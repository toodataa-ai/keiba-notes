# 完全版予想アーカイブ運用ルール

KEIBA AI NEXT では、JRAメインレースの公式PDFは **発走前に確定した完全版予想** だけを保存・公開します。

## 必須ルール

1. 予想は発走前に完全版として確定し、その時点のスナップショットを保存する。
2. 結果を知った後に予想本文を作り直したり、追記で内容を都合よく変更したりしない。
3. 全出走馬の診断を保存する。`races.json` の `field_size` と全頭診断数が一致しなければ公開用PDFを生成しない。
4. 発走時馬場予測、馬場質、バイアス、類似条件タイム、同条件直接実績、STEP1、展開・隊列、再監査、全頭診断、◎弱点監査、STEP2、能力本線、期待値追加、緊急リスク、推奨買い目、最終結論を完全版の必須要素とする。
5. 要約ページだけを公式PDFとして保存してはならない。
6. 結果・収支・回顧は、発走前予想のスナップショットとは分離して管理する。予想スナップショットは不変とする。
7. プロンプトを改良した場合は `docs/data/prompt_history.json` に変更内容と理由を記録する。

## 自動チェック

`.github/scripts/render-pdfs.mjs` は、2026-10-04以降のJRAメインレースについて、完全版マーカー・必須セクション・全頭診断数を検証します。条件を満たさない場合はGitHub Actionsを失敗させ、要約版や欠損版のPDFが公式版として更新されないようにします。

## 2026-10-04 の復旧について

毎日王冠と京都大賞典は、発走前に作成済みだった元の完全版PDFから内容を復旧しました。復旧用ソースは `docs/full-reports/*.txt.xz.b64` として保存し、そこから完全版HTMLとPDFを再生成します。

今後の新規予想は、復旧用圧縮テキストではなく、発走前に完成した完全版HTMLそのものを `docs/reports/` に保存することを標準とします。
