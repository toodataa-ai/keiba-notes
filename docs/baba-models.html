何を根拠に予測するか

JRA公式の当日朝の含水率をアンカーに、降雨量、雨上がりからの経過時間、気温、風、日照を使って発走時へ更新します。芝は競馬場ごとに含水率と馬場状態の目安が異なるため、競馬場別に扱います。

Stage A
前日 → 当日朝

過去履歴と気象から朝の含水率を推定。競馬場別バックテスト完了後のみ正式利用。

Stage B
朝実測 → 発走時

JRA朝実測を起点に、その後の雨・乾燥条件で更新。

最終出力
4状態の確率

良・稍重・重・不良を合計100%で表示。含水率だけで断定しません。

精度・バックテスト

可視化ルール： MAE / RMSE / ±1pt / ±1.5pt / ±2pt、雨天・乾燥別を、実測バックテストが存在するモデルだけ表示します。未検証モデルには数値を作らず「未検証」と表示します。

予測ロジックの監査ポイント

  1. 他競馬場の係数を無断流用しない
  2. 京都は2023年再開後を現行レジームとして優先
  3. 予測時点より後の情報を学習・再現に混入させない
  4. 含水率だけで馬場状態を決めない
  5. バックテスト前は「Pilot」と明示する

Data policy: JRA公式含水率は2018-07-27以降、クッション値は2020-09-11以降を基本母集団。ページ自体は既存予想機能から独立した追加ページです。
