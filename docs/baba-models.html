どう予測しているか

Stage A：前日 → 当日朝公式含水率と気象履歴から、当日朝の状態を予測します。
Stage B：朝実測 → 発走時朝の実測、降雨、乾燥条件から、レース時点の良・稍重・重・不良を確率で予測します。
本番接続は承認制候補になっても勝手に本番AI予想へ切り替えません。

本番採用までのルール

可視化ルール： 実測バックテストが存在する指標だけ表示します。「Baseline」は比較対象であり、モデル精度そのものではありません。
  1. Stage Aは複数年・独立サンプルでLOYO/時系列検証を行い、naive baselineより改善すること。
  2. Stage Bはレース時点のJRA公式馬場状態を教師ラベルにし、現行heuristicよりLog Loss/Brier Scoreを改善すること。
  3. 乾燥ケースだけでなく雨天・馬場変化ケースを別監査すること。
  4. 未来情報混入なし・再現可能なバックテストであること。
  5. 候補 → 検証済み、本番モデル置換は承認必須。

データ方針：JRA公式含水率は2018-07-27以降、クッション値は2020-09-11以降を基本母集団。京都は2023年再開後を現行レジームとして優先します。
