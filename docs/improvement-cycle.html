03 / 戦歴別研究・テーマごとのロードマップ

E0・E1・E2はどこまで進んでいる？

研究には既存の発走前固定データがあります。ただし勝率・3着内確率と結果を突合できるデータがないと、「予測が正しかったか」は評価できません。既存の収集・回顧は消さず、別の成果として表示します。

05 / 20レース到達後の判断

十分に集まったら、何をする？

① 性能を比較

◎・印・勝率予測・3着内確率・回収率・損失リスクを比較

② 偏りを監査

別の開催週、芝／ダート、条件別、過剰適合を検証

③ 人が承認

採用／追加検証／不採用をA/B/Cルールで決定。自動採用はしない

研究初期診断の「30頭分」と、正式モデルの「最低20レースの新旧比較」は別々の条件です。現行の正式版・発走前予想・買い目原本・既存PDFは変更しません。

集計元・判断条件を確認する

テーマ別観測レースは同一レースが複数テーマに重複するため合計しません。E0/E1/E2のレースも区分間で重複があります。発走前研究データと新旧比較の実績を合算せず、予想の結果を見た後のデータ補完もしません。
