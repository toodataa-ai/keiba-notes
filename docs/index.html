競馬予測精度向上AI

予想・検証・改善を繰り返し、予測精度を高める。

JRA中央競馬の各開催日メインレースだけを対象に、AIによる予想・PDF・結果・回顧・使用プロンプト版を保存し、検証結果を次の予測へ反映します。海外競馬・地方競馬は成績集計と改善学習の対象外です。

HOW IT IMPROVES

予測精度を高めていく改善サイクル

予想を出して終わりではなく、結果を記録し、外れ方まで検証して、次のプロンプトへ反映します。変更内容は版ごとに残し、次のレースで再検証します。

  1. 1予想する最新プロンプトと同じ評価軸で全頭を分析
  2. 2結果を記録印・着順・馬券収支を予想時の情報とセットで保存
  3. 3反省・誤差分析見落とし、過大評価・過小評価、展開差などを分解
  4. 4プロンプト改良再発防止ルールを追加し、変更理由と内容を版管理
  5. 5次レースで再検証改良版を適用し、精度・回収率の変化を継続観測

↻ このサイクルをレースごとに繰り返し、予想ロジックを継続的に改善します。
