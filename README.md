【この条件で狙え！】騎手格言2026
チャリオット2026/03/30
騎手格言2026のまとめになります。各ジョッキーの特性を少しでも把握しておくと、騎乗に対するストレスが少しは緩和されるのでおすすめです。
すべて無料公開としていますが、的中したときにはＲＴや的中報告をしてもらえると嬉しいです！

Ｃ・ルメール　芝2400m以上、5枠よりも外
・折り合いの達人で、長距離戦での信頼度は抜群。外枠でも馬を自在にコントロールできるのが強み。 ・内枠だとやや成績が下がる傾向があり、スムーズに走れる外枠の方が自信を持って狙いやすい。 ・ダートや短距離では期待値が下がる。
戸崎圭太 　中山の継続騎乗(芝内枠、ダート外枠)
・関西よりも関東でこそ。高速上がりのレースだと差し損ねるので、東京は条件が合わないことが多い。  ・上がりがそれなりにかかる条件が得意なので、中山がベスト。 ・芝は4枠より内、ダートは5枠より外だと期待値が高い。
松山弘平 　ダート1800m以上の先行馬
・芝で差し馬の瞬発力を引き出すよりも、ダートで先行馬を粘らせる技術が高い騎手。  ・1800m以上の先行馬では安定した成績を残しており、特に米国血統の馬とは相性抜群。 ・大型馬もしっかりと動かせるパワーがある。
横山武史 　ローカルの芝
・先行意識が高く、瞬発力を引き出す競馬よりも、早めに動いて持続力を活かす乗り方が得意。  ・ローカルでは、出走する馬のタイプが手に合いやすいことや、馬質に恵まれることも好成績の要因となっている。  ・新馬戦は特に狙いたい条件となる。
坂井瑠星 　3勝クラス以上、ダート1800m以上
・フォーエバーヤングのようにダートで先行して粘らせるアメリカンな競馬が得意。 ・大舞台経験が豊富なこともあり、上級条件になるほど期待値は高い。  ・芝の瞬発力タイプの馬で勝てるかが、更に一流になるための課題ではある。
川田将雅 　前哨戦から能力全開
・クラス別ではG2の成績が突出して良い。 ・前哨戦だからといって手を抜かない騎乗スタイル。トライアルが一番の狙い目。  ・上級条件になるほど、長距離での成績は下降。外枠での折り合いにも不安がある。  ・本来はズブい馬を動かすタイプではある。
岩田望来　芝の距離短縮
・とにかく芝での期待値が高く、2着よりも勝ち切れる点がポイント。狙うなら単勝がおすすめ。  ・馬を動かすタイプなので、距離短縮の方が成績は良く、逆に距離延長は割り引き。  ・ノーザンファーム生産馬以外だとさらに期待値は上昇する。
佐々木大輔　ローカル芝2600m
・ズブい馬を動かすタイプではあるが、期待値は長距離戦で高い。 ・上がりがかかる長距離戦が良いので、狙い目はローカルの2600m。 ・2025年はリーディング9位と成長中。今後は馬質向上と共にどう変化していくか楽しみなジョッキー。
横山和生　ダートの距離延長
・揉まれずに運ぶことが好走パターンなので、距離延長で先行しやすい条件が合う。 ・最近は特にダートでの期待値が高いので、ダートの距離延長が一番の狙い目。 ・馬群の中でのレースを嫌い、捲りを仕掛けることもある。嵌る条件では要注意。
高杉吏麒 ☆関西圏の1400m以下
・中京コースで好成績を残しているように、コース理解も高い騎手。  ・ただ、現状は短距離での期待値が高く、距離が伸びると割り引き。  ・関東では馬質的に成績が今は残せていない。 ・今後の伸びしろは大きい騎手なので、変化には敏感になっておきたい。
津村明秀　関東圏の芝1600～2000m
・武器は先行力。前残りレースで穴をあけるジョッキー。 ・関東のマイルから2000mがベストで、差しが決まらない馬場が絶好の狙い目。 ・東京や新潟外回りなど、直線が長いコースでの積極策が特徴的。
横山典弘 ☆芝の継続騎乗
・テン乗りは自己紹介なのでポツン注意 ・継続騎乗で馬を理解してから本気の騎乗をしてくる。 ・ダートよりは芝の方が期待値は高い。  ・ちなみに乗り替わりでも横山和生からの乗り替わりは結果を残しているのは豆知識。(武史からは×)
岩田康誠　牡馬でオープン以上の継続騎乗
・継続騎乗で自分仕様に馬を作り替えていくジョッキー。  ・近年は騎乗数も少なくなっており、オープン以上で本気を出してくるイメージ。 ・勝負どころでのイン突き(近道)は健在だが、牝馬では成績が良くないので注意。
北村友一　芝の重賞、距離延長
・自分から馬を動かすタイプではなく、素材引き出し型の騎乗スタイル。  ・強い馬に乗せてこそなので、ノーザンファーム生産馬とは相性が良い。  ・芝の上級条件で距離延長だと能力を発揮させやすい。 ・馬群を割れるタイプではないので、外枠がベスト。
団野大成　関西圏の芝1400m以下
・短距離が主戦場となる騎手で、長距離での差しは苦戦している。  ・狙い目となるのは芝1400m以下。 ・関東では騎乗数が少なく、関西圏が狙い目。 距離は延長よりも短縮が得意。
柴田善臣　関東圏での継続騎乗
・現役最年長、悠々自適スタイルで今も競馬を楽しむジョッキー。  ・中山、東京などの関東圏が主戦場。 ・継続騎乗で馬の個性を理解している馬で職人的騎乗を見せることがある。 ・騎乗数は少ないが、期待値は意外と高いので条件次第では狙っていきたい。
西村淳也　芝の新馬、未勝利戦
・先行意識が高く、積極的な騎乗が持ち味。 ・その積極策により、新馬と未勝利戦で人気薄を持ってくることが多い。  ・積極的ではあるが、馬を動かすタイプではないので、ダートよりも芝向き。 ・中京の芝では積極策がハマりやすいので狙い目。
菅原明良　芝1400～1600m
・基本的に先行意識は低い騎手。  ・芝1400～1600mで、差しが決まりやすい東京や新潟などの広いコースが最も得意。 ・最内枠だと先行策をとることも多いので、1枠は好成績。 ・大型馬を動かせる騎手だが、軽量馬も成績は非常に良い。積極的に狙いたい。
丹内祐次　関東圏のダート先行馬
・騎乗スタイルというよりも、乗っている馬のタイプ的に先行して粘る形が多くなる。 ・関西圏では馬質が落ちるので、狙えるのは関東圏のダート先行馬。  ・内枠か8枠での成績が良く、中枠では期待値が下がるので注意。
吉村誠之助　欧州型ノーザンダンサー系の馬で
・成長著しい若手だが、知名度が上がったことで期待値は下降気味。  ・馬をしっかりと動かしてくるタイプなので、瞬発力型よりはスタミナ型の欧州型ノーザンダンサー系の馬と相性が良い。 ・外枠よりも内枠で好成績を残している。
田口貫太　京都ダートの牡馬
・好走する場所が京都ダートに偏っている。  ・正直、現状では京都ダートだけ買えば良いという感じ。  ・先行意識はあまり高い騎手ではないので、ある程度行きっぷりが良い馬の方が良い。 ・ダートだけに、基本は牡馬の方が期待値は高い。
斎藤新　前走上がり2位以内の馬
・安定感のあるジョッキーではないが、思い切りのある騎乗で激走することがある。  ・末脚を持っている馬と相性が良く、近走速い上がりを使っている馬に乗ってきた時は狙い目。  ・馬群を捌けるタイプではないので、外枠の方が得意。たまに捲りもする。
武豊　レースを支配する巧みな逃げ
・体内時計では並ぶ者はいない。絶妙なラップコントロールでレースを支配する。 ・分かりやすい逃げ馬よりも、前走で逃げ損ねた馬で逃げるパターンが期待値は高い。 ・逆に逃げて好走したあとは割り引きたい。狙い所を定めないと期待値は下がる。
三浦皇成　中山の未勝利戦
・瞬発力引き出し型の騎手ではなく、腕力で走らせるタイプ。 ・ズブい馬やタフな馬場で力を発揮するので、中山の未勝利戦が最も合う条件。 ・瞬発力が求められる条件や、コース取りが重要になる条件では割り引きが必要。
小林美駒　ダートで前走逃げている馬
・とにかく逃げることに徹する騎乗をするので、ダートの下級条件では意外と信頼度が高い。 ・素直に前走で逃げている馬に乗ると、再現性の高い騎乗をしてくる。 ・逃げられずに馬群に入ってしまうと対応はできないので、とにかく逃げられるか。
R・キング 　日本の芝馬に適応したバランス
・馬上でのバランスが非常に安定しており、日本馬の瞬発力を存分に発揮させるジョッキー。  ・短期免許の外国人騎手の中では日本適性ナンバーワン。 ・芝の内枠が好成績。 ダートはやや期待値下がるが、スピード活かす東京は得意。
古川吉洋　芝で過小評価される高期待値騎手
・とにかく毎年、芝での期待値が高い騎手。  ・どこで来るか分からないが、年間のどこかで大穴を持ってくる。  ・条件を絞るならば、高速馬場はあまり良くない。やや渋った馬場かローカルで狙うのが効率は良さそう。
石川裕紀人　6枠より外のダート、継続騎乗
・継続騎乗でこその騎手。  ・先行意識が低く、内枠だと下げてポジションを悪くするので、人気馬では要注意。 そういう意味では、ダートの外枠が一番安心して見られる条件。 ・6枠より外のダートで継続騎乗であれば買えるパターンとなる。
小沢大仁　ダート1700m
・全体的にはあまり期待値は高くなく、特に上級条件ではかなり厳しい成績となっている。  ・一番の狙い目はローカルのダート1700m。馬券内率は決して高くはないが、積極策で大穴をあけることがある。  ・小倉では芝でも狙えることは覚えておきたい。
浜中俊　前走上がり3位以内の馬
・騎乗スタイルとしては、悪く言えば雑。 ・隊列を考えて、馬群の隙間から抜けてくるような騎乗はあまりなく、勝負どころから大外をぶん回すような乗り方をする。  ・末脚がしっかりしている人気馬なら安定して走る。ただ勝ち切れないことは多い。
丸山元気　ローカルのメインレース
・実に狙いにくいジョッキー。  ・特徴としては、下級条件では全く活躍しないこと。一方、重賞レベルとなると馬質的に厳しい。  ・狙えるのは3勝クラスからオープンクラス。特にローカルのメインレースでは本気を出してくる。
池添謙一　1番人気に応える
・馬の能力引き出し型ジョッキー。 ・気難しい馬のコントロールも上手い。  ・ズブい馬を動かすタイプではないので、人気薄で穴をあけるというよりも、人気馬をしっかりと走らせてくる。 ・1番人気での信頼度は抜群で、人気でも期待値は高い。
大野拓弥　6枠より外の1番人気
・実は1番人気での信頼度はJRAでトップクラスで高い騎手。 ・馬群の中での競馬はあまり得意ではないので、外枠だとさらに信頼度が増す。 ・タイプとしては、タフな馬場での差しを得意とするが、今年は1番人気で狙っていきたい。
木幡巧也　斤量53キロ以下での激走
・なかなか好走ゾーンの狭い騎手ではあるが、ここ数年は軽斤量時に大穴を激走させている。 ・53キロ以下での騎乗数は少ないので、出走してきた時は取捨選択せずに、すべて買っておいて激走を待つのが良いだろう。
松若風馬　杉山晴紀厩舎の条件戦担当
・杉山晴紀厩舎の主戦と言えば、松山・川田・坂井などだが、条件戦では松若騎手をよく起用している。 ・騎乗停止からの復帰後も、良い馬を回してもらっており、馬券内率は非常に高い。 ・差しよりも先行してこそのタイプ。先行馬で狙いたい。
内田博幸　ダートで500キロ以上の大型馬
・日本一の豪腕。とにかく力任せに追いまくる。ズブい馬を動かす技術に特化している。 ・狙えるのはスピードが求められないダートで500キロ以上の大型馬。 ・なかなか動かない馬を激変させるパターンに注目したい。
横山琉人　ダート1400m以下の外枠
・昨年後半は不振だったが、徐々に復調の気配はある。 ・主戦場はローカルではあるものの、中央開催でも人気薄を持ってくることがある。 ・ダート1400m以下の5枠よりも外の時に期待値が上昇するので、紐穴には加えておきたいジョッキー。
西塚洸二　藤原英昭厩舎の芝1800m以上
・騎乗数が断然多いのが藤原厩舎。この厩舎によって、救われていると言っても良いジョッキー。 ・短距離は苦手にしており、中距離以上で好成績を残している。 ・特に藤原厩舎での芝1800m以上は特注条件。 ・ダートでは8枠の先行馬が狙い目。
舟山瑠泉　小回りの芝1800m、斤量3キロ減
・芝でコースロスを抑えたイン突きで穴をあけるタイプ。 ・展開によってはマクリをかけることもある。 ・現状は馬質的に正攻法では勝ちにくいので、乗り方を工夫すれば勝負になるコースが良い。 ・小回りの中山や福島の芝1800mを減量で狙う。
原優介　1400m以下の大穴演出家
・年に数回、1400m以下で単勝オッズ100倍以上の馬を持ってくる。 ・特徴としては、その多くが差しによるもの。超大穴馬で目の覚めるような末脚を発揮することがある。 ・どこで爆発するかは読めないので、単勝100倍以上の馬を宝くじ感覚で買うと良い
幸英明　500キロ以上の牡馬
・大型馬を動かすパワージョッキー。瞬発力タイプや繊細な牝馬とは相性が悪い。 ・期待値が高いのは500キロ以上の牡馬。 ・ダートの方が得意ではあるが、人気薄での激走は芝であるので、条件合致の時は警戒しておきたい。
杉原誠人　芝のオープン以上で人気に応える
・馬の能力引き出し型で、折り合いに難のある馬も上手に乗りこなす。 ・なかなか馬質に恵まれないが、芝で能力の高い馬に乗ればかなり安定している。 ・逆にズブい馬を動かすことは苦手で、下級条件やダートでは割り引き。
菱田裕二　ダート1700mで前走5着以内の馬
・最近は馬質が低下気味。主要開催ではなかなか勝負になる馬に乗れていない現状がある。 ・狙えるのはローカルのダート1700m。 ・ここでも2桁人気の馬に乗ることが多く、前走5着以内でそれなりに勝負になりそうな馬に乗った時は期待値が高い。
松本大輝　ダート1000mの距離短縮
・身長176cmとJRAで最も背が高いジョッキー。 ・その高身長から馬をしっかり動かす技術には優れる。 ・折り合い技術に長けているわけではないので、力押しのできるダート1000mが狙い目。 ・距離短縮で、馬を動かしていく形がベスト。外枠だとなお良い。
永島まなみ　ダート外枠の人気馬
・期待値を考えると、かなり厳しい成績となっている現状。 ・内枠で馬群に包まれると何もできずに終わることが多い。 ・買えるのは、ダート外枠で3番人気以内の人気馬。このパターンでは能力通りに走ってくる可能性が高い。 ・内枠では逃げが必須。
石橋脩　ダート未勝利の距離短縮
・馬上でのアクションが激しい、癖の強いジョッキー。 ・ダートの下級条件で少し能力的に足りない馬を頑張らせる乗り方に向いている。 ・距離短縮でややズブめの馬を動かす形が最も期待値が高い。
鮫島克駿　中京ダートの1枠
・天皇賞のジャスティンパレス以降、成績が急降下。 ・なかなか狙える条件がないのが正直なところだが、本来はトラックバイアスなども読める騎手。 ・今は芝よりダートで成績が安定しており、癖のある中京の内枠が最も期待値は高い。
荻野極　関東ローカルの乗り替わりで無双
・結婚後から期待値爆上がり、今最も注目のジョッキー。 ・特に関東ローカルでは、乗り替わりで良い馬が集まってきており、継続騎乗以上に好成績を残している。 ・今の勢いだと、中央開催でも狙える騎手になっていく可能性が高い。
田辺裕信　ローカルダートの距離短縮
・トラックバイアスや展開よりも馬のリズムを最優先するジョッキー。 ・そのため、芝の前残り馬場などでは、後方で何もせずに終わることも多く、一見不可解な騎乗も目立つ。 ・安定した成績を残すのはローカルのダート。特に距離短縮は狙い目。
長浜鴻緒　東京ダート1600m、距離延長以外
・芝よりもダート。 ・距離延長では成績急降下。同距離または距離短縮の馬を動かしていく乗り方がベスト。 ・先行意識は低めで、末脚が重視される東京ダートが得意条件。
今村聖奈　新潟1200m以下の牝馬
・女性ジョッキーの中では最も先行意識が低い。どこでも似たような乗り方をするので、コースによる得意不得意がある。 ・中京のようなトリッキーなコースは苦手で、得意なのは断然新潟。1200m以下では芝ダート問わず好成績。 ・特に牝馬と相性が抜群。
