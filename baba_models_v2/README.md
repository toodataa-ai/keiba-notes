# JRA全10場 馬場予測 v2 additive layer

## 目的
既存の中山・阪神モデルおよび競馬予想プロンプトを変更せず、JRA全10場の芝/ダートを段階的にカバーするための追加レイヤー。

## 非破壊方針
- 既存ファイルを削除・上書きしない。
- `latest_prompt.json`、`prompt_history.json`、`races.json`、HTML/PDF生成処理には触れない。
- 既存の検証済み/パイロットモデルを自動的に置換しない。
- 本ディレクトリは opt-in。明示的に `baba_models_v2.predict` を利用した場合だけ動く。
- 他場モデルの係数を「検証済みモデル」として流用しない。

## 対応
札幌、函館、福島、新潟、東京、中山、中京、京都、阪神、小倉 × turf/dirt。

`config.json` は競馬場別のJRA含水率目安に基づく確率化設定を保持する。`predict.py` のStage Bは当日朝のJRA実測含水率をアンカーに、降雨・乾燥時間・気温・風・日照から発走時レンジを更新する。

## 重要
現時点の全場共通Stage Bは **pilot operational heuristic** であり、競馬場別バックテスト済みモデルではない。出力にも必ずその旨を含める。

中山・阪神については既存モデルがあるため、予想運用では従来モデルを優先する。本レイヤーはフォールバック/拡張用であり、自動置換しない。

## 次段階
各場についてJRA公式履歴からStage Aデータセットを作り、LOYOまたは時系列ホールドアウトでMAE/RMSE等を検証する。基準を満たした場・走路だけを個別v1.0へ昇格する。

京都は2023年再開後を現行レジームとして優先し、旧京都を無条件に混合しない。
