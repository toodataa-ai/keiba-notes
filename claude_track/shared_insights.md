# 共通の知見（ChatGPT にも渡すもの）

ChatGPT と Claude の**どちらの予想にも使える、データで裏づけのあるもの**だけをここに置く。
予想そのもの（印・買い目）は渡さない。比較の公平さを保つため。

## 渡し方（承認が必要）
1. 回顧や研究で共通の知見が見つかる → ここに「候補」として追記（根拠のファイルと数字つき）。
2. Issue（A=ChatGPT の次の指示文に反映／B=保留／C=採用しない）でユーザーに確認。
3. A のときだけ、ChatGPT に貼る指示文の追記文を作る（ユーザーが貼る。自動では書き換えない）。
4. 反映した日と版を下の台帳に残し、反映前後の成績を別々に追う。
