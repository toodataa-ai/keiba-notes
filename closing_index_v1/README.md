# 補正上がり3F指数 v1 (ACI v1)

目的: 上がり3Fの絶対秒数や順位をそのまま評価せず、**同一レース内の相対速度**と**4角位置取りによる脚の温存差**を補正して、過去走の末脚性能を比較可能な補助指標へ変換する。

## 位置づけ

- 新しい「⑩評価軸」は作らない。
- STEP1の⑨基礎能力、②展開、類似条件Time Indexの補助指標として使う。
- v3.0本体には、バックテストで有用性が確認できるまで組み込まない。
- ACIだけで印を決めない。走破能力、展開適合、馬場、直接実績を優先する。

## v1の定義

各過去走について以下を計算する。

1. 同一レース内で上がり3Fの中央値 `race_median_3f` とロバスト分散を求める。
2. `raw_close_z = (race_median_3f - horse_last3f) / robust_scale`
   - 正なら同一レース平均より速い。
   - 馬場、距離、レース全体の時計水準は同一レース比較で大きく相殺される。
3. 4角位置を頭数で0〜1へ正規化し、位置取り帯へ分類する。
   - front: 0〜20%
   - stalk: 20〜40%
   - mid: 40〜65%
   - rear: 65〜100%
4. 学習期間で `芝/ダート × 距離帯 × 位置取り帯` ごとの平均 `raw_close_z` を求める。
5. 後方待機ほど速い上がりを出しやすい構造を除去する。
   - `adjusted_z = raw_close_z - expected_raw_close_z(surface, distance_band, position_band)`
6. 表示指数へ変換する。
   - `ACI = clip(100 + 10 * adjusted_z, 70, 130)`
   - 100 = 位置取り補正後の標準
   - 110前後 = おおむね1標準偏差分強い末脚

## なぜ4角位置を補正するか

最後方から33.0秒と、好位から33.3秒を単純比較すると前者を過大評価しやすい。後方馬は道中で脚を温存できるため、後方位置そのものに「上がりが速くなりやすい期待値」がある。ACIはその期待値を差し引く。

## v1で意図的に入れないもの

- ラップ列からの明示的ペース補正
- 進路・不利の定量補正
- コーナー外々距離ロス補正
- 坂・直線長の個別係数

これらはデータ品質を確認後のv1.1以降で検討する。v1では複雑化より、再現可能でリーケージのない基礎指数を優先する。

## バックテスト

公開JRAデータ由来のKaggleデータセット `takamotoki/jra-horse-racing-dataset` の race_result を使用する。

- 学習期間: 2015〜2018年
- テスト期間: 2019〜2021年7月
- 対象: JRA平地、正常完走、上がり3Fと4角位置が取得できる走り
- 評価は**次走予測**で行う。対象レースの結果から作ったACIを同じレースの予測に使わない。
- 各馬の前走・直近3走中央値を次走の特徴量として使用する。

比較する指標:

1. 前走の上がり3F絶対秒数（小さいほど高評価）
2. 前走の同一レース相対上がり `raw_close_z`
3. 前走ACI
4. 直近3走ACI中央値

評価指標:

- feature 1位馬の勝率
- feature 上位3頭による実際の3着内馬カバー率
- 実勝馬のfeature平均順位
- top3分類AUC

## 採用判断

ACIは以下を満たす場合にv3.xへ統合候補とする。

- raw_close_zより複数指標で一貫して改善、または同等性能で解釈性が改善
- 芝・ダート双方で極端な逆効果がない
- 特定競馬場・距離帯だけの偶然に依存しない
- 次走評価で改善が確認され、同一レース結果への当てはめだけではない

弱い場合は本体へ入れず、pilotのまま残す。
