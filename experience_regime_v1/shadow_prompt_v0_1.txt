Experience Regime E0/E1/E2 Shadow Prompt v0.1
作成日: 2026-10-06

【位置づけ】
本ファイルは競馬予想・完全版プロンプト v3.1へ追加して使う研究用Shadow差分である。
本差分はSTEP1順位、◎○▲△×、ABC評価、STEP2、買い目を変更してはならない。
目的は経験量別の誤差を測るための発走前データを保存することだけである。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-00 Shadow対象レースの選定
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Shadow研究の母集団はJRAの1R〜12Rすべてとする。
正式サイトで公開するメインレース予想だけに限定しない。

対象レースは次の二系統で構成する。

A. official_prediction
正式予想として作成するメインレース。Shadowにも全件含める。

B. stratified_sample
残りの1R〜12Rからカテゴリ別に層化抽出した研究専用レース。

カテゴリ:
- debut = 新馬
- maiden = 未勝利
- class_1 = 1勝クラス
- class_2 = 2勝クラス
- class_3 = 3勝クラス
- open_listed = OP・L
- graded = GIII・GII・GI

抽出はexperience_regime_v1/sampling.pyの固定ハッシュ方式で発走前に確定する。
結果を見た後の対象レース差し替えは禁止する。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-01 Experience Regimeの機械分類
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

各馬について、対象レース発走前時点の通算出走数 starts_before_race を取得する。

E0 = 0戦
E1 = 1〜3戦
E2 = 4戦以上

分類はstarts_before_raceだけで決める。
年齢、人気、クラス、評判、血統、調教、馬体、厩舎コメント等でRegimeを変更しない。

取得できない場合は推測しない。experience metadataを欠測扱いとする。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-02 結果リーク禁止
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

対象レース、race_context、starts_before_race、Regimeはすべて予想時点で確定し、prediction snapshotへ保存する。
Grade Aでは他の予想情報と同じproof commitに含める。
レース結果を見た後の修正は禁止する。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-03 本線への影響禁止
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Shadow v0.1では以下を禁止する。

・E0だから減点する
・E1だから補正する
・E2だから信頼度を加点する
・RegimeだけでABC評価を上下する
・Regimeだけで印を変更する
・未検証の固定σ、固定縮約率、固定ボーナス／ペナルティを使用する

現行v3.1の判断をControlとしてそのまま保存する。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-04 prediction snapshot出力
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Shadow対象レースでは、既存prediction JSONへ以下を追加する。

"race_context": {
  "venue": "<競馬場>",
  "race_no": <1-12>,
  "race_name": "<レース名>",
  "race_category": "debut|maiden|class_1|class_2|class_3|open_listed|graded",
  "sample_origin": "official_prediction|stratified_sample"
},
"experience": {
  "model_version": "e012-shadow-v0.1",
  "horses": {
    "<馬番>": {
      "starts_before_race": <整数>,
      "regime": "E0|E1|E2"
    }
  }
}

regimeは監査用の冗長値であり、評価時にはstarts_before_raceから再計算して一致確認する。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-05 Shadow観測項目
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

本線の予想値をRegime別・カテゴリ別に後から比較できるよう、既存の以下を維持する。

・STEP1 ranking
・◎○▲
・勝率（出せる場合）
・3着内率（出せる場合）
・情報cutoff
・prompt version / manifest

結果確定後、experience_regime_v1/analyze.pyで以下を集計する。

・E0/E1/E2別の実勝率／実3着内率
・予測勝率平均／予測3着内率平均
・勝率Brier／3着内Brier
・STEP1平均順位
・◎○▲選出率
・race_category × E0/E1/E2の同一指標
・official_prediction / stratified_sample別の同一指標

「E1全体が弱い」だけでなく、「未勝利E1だけ過信」「1勝クラスE1は安定」のように分解する。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-06 次段階へ進む条件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Shadowデータが蓄積するまではμ/σ補正を本線へ入れない。

次段階では、
latent ability μ + uncertainty σ
の枠組みをChallengerとして別実装する。

仮説例:
・E0は事前分布への依存が大きくσが大きい
・E1は少数実戦でμを更新するが、単走への過適合を避ける
・E2は実戦情報が十分で現行能力評価の比重を高くできる

ただし、上記は検証対象であり本番ルールではない。
カテゴリごとの安定性も確認してからChallengerへ進む。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-AUD 監査
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ 1R〜12Rを母集団としたrace poolから結果判明前に対象レースを固定した
□ 正式予想レースと層化抽出レースをsample_originで区別した
□ race_noとrace_categoryを発走前に保存した
□ 全馬のstarts_before_raceを発走前情報から取得した
□ 0=E0、1〜3=E1、4以上=E2で機械分類した
□ 欠測を推測補完していない
□ Regimeを理由にv3.1のSTEP1順位を変更していない
□ Regimeを理由に印を変更していない
□ 未検証の固定補正を入れていない
□ experience metadataをprediction snapshotへ保存した
□ Grade Aではproof commitに含めた

以上を満たしたときのみe012-shadow-v0.1として記録する。
