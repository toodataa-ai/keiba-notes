Experience Regime E0/E1/E2 Shadow Prompt v0.1
作成日: 2026-10-06

【位置づけ】
本ファイルは競馬予想・完全版プロンプト v3.1へ追加して使う研究用Shadow差分である。
本差分はSTEP1順位、◎○▲△×、ABC評価、STEP2、買い目を変更してはならない。
目的は経験量別の誤差を測るための発走前データを保存することだけである。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-01 Experience Regimeの機械分類
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

各馬について、対象レース発走前時点の通算出走数 starts_before_race を取得する。

E0 = 0戦
E1 = 1〜3戦
E2 = 4戦以上

分類はstarts_before_raceだけで決める。
年齢、人気、クラス、評判、血統、調教、馬体、厩舎コメント等でRegimeを変更しない。

取得できない場合は推測しない。experience metadataを欠測扱いとする。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-02 結果リーク禁止
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

starts_before_raceとRegimeは予想時点で確定し、prediction snapshotへ保存する。
Grade Aでは他の予想情報と同じproof commitに含める。
レース結果を見た後の修正は禁止する。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-03 本線への影響禁止
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Shadow v0.1では以下を禁止する。

・E0だから減点する
・E1だから補正する
・E2だから信頼度を加点する
・RegimeだけでABC評価を上下する
・Regimeだけで印を変更する
・未検証の固定σ、固定縮約率、固定ボーナス／ペナルティを使用する

現行v3.1の判断をControlとしてそのまま保存する。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-04 prediction snapshot出力
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

可能な限り全出走馬について、既存prediction JSONへ以下を追加する。

"experience": {
  "model_version": "e012-shadow-v0.1",
  "horses": {
    "<馬番>": {
      "starts_before_race": <整数>,
      "regime": "E0|E1|E2"
    }
  }
}

regimeは監査用の冗長値であり、評価時にはstarts_before_raceから再計算して一致確認する。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-05 Shadow観測項目
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

本線の予想値をRegime別に後から比較できるよう、既存の以下を維持する。

・STEP1 ranking
・◎○▲
・勝率（出せる場合）
・3着内率（出せる場合）
・情報cutoff
・prompt version / manifest

結果確定後、experience_regime_v1/analyze.pyでE0/E1/E2別に以下を集計する。

・実勝率／実3着内率
・予測勝率平均／予測3着内率平均
・勝率Brier／3着内Brier
・STEP1平均順位
・◎○▲選出率

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-06 次段階へ進む条件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Shadowデータが蓄積するまではμ/σ補正を本線へ入れない。

次段階では、
latent ability μ + uncertainty σ
の枠組みをChallengerとして別実装する。

仮説例:
・E0は事前分布への依存が大きくσが大きい
・E1は少数実戦でμを更新するが、単走への過適合を避ける
・E2は実戦情報が十分で現行能力評価の比重を高くできる

ただし、上記は検証対象であり本番ルールではない。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ER-AUD 監査
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ 全馬のstarts_before_raceを発走前情報から取得した
□ 0=E0、1〜3=E1、4以上=E2で機械分類した
□ 欠測を推測補完していない
□ Regimeを理由にv3.1のSTEP1順位を変更していない
□ Regimeを理由に印を変更していない
□ 未検証の固定補正を入れていない
□ experience metadataをprediction snapshotへ保存した
□ Grade Aではproof commitに含めた

以上を満たしたときのみe012-shadow-v0.1として記録する。
