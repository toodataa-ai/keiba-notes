## 2026-11-01 運用更新：チャット起点で明示指示する単一記事の手動取得

利用者の運用は「チャットでその都度指示したときだけ無料公開データを取りに行く」方式。GitHub Actions の workflow_dispatch はユーザー指示による単発起動に限定する。cron、workflow_run、push などの起点で外部サイトから時計を反復収集しない。

- **手動モード：** E012 one free workout source before race start / E012 manually instructed prereace free workout SOURCE HASH proof は明示した一つの無料記事URLのみ取得し、サイトの robots.txt、発走前の出馬表Git初回固定、発走前時刻、馬名・時計の整合性を検査する。時間制限・URL制限を満たさなければそのレースは未評価。
- **定期/大量モード：** automatic_reuse=permission_unverified とし停止継続。手動でも毎日何十件も依頼すれば自動巡回と同じ負荷になり得るため、単発前提のアクセスに限る。
- **出典表示：** 「出典：うましる」＋正確な記事URLを明記し、記事文章、評価コメント、写真、映像、記事全表の転載はしない。保管は限られた数値事実の短期研究用、公開Gitには時計を含めず SHA-256 等のメタデータだけ保存する。
- **発走前証拠：** 調教データの研究用取得と、予想モデルの印・勝率の発走前固定は別。研究用取得が成功しても旧JRA正式予想や⑦調教一律B−は変更しない。
- **利用条件：** 画面の引用・リンク方針は限定的な引用の出典表記を定めたもの。無制限の機械取得許可ではない。個別記事側に禁止・アクセス拒否等があればその場で停止。データ権利に関する問い合わせを完全不要と断定するものでもない。
- **デグレ禁止：** 予想・印・買い目・過去結果・回収率などの既存データは完全不変。
